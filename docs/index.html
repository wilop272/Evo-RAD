01 / Abstract

An evolving agent for retrieval-based diagnosis

Large-scale pretrained foundation models have revolutionized general medical screening, but often falter on rare diseases because such conditions are underrepresented in real-world clinical datasets. Retrieval-augmented diagnosis attempts to mitigate this, but conventional static methods succumb to the hubness problem — retrieving visually similar but semantically incorrect common diseases.

We propose Evo-RAD, a self-evolving agentic framework that transforms evidence acquisition into a dynamic decision-making task. Retrieval is formulated as a Markov Decision Process where a graph-based agent observes the reference-set state and executes actions to purge discordant evidence, acquire pathologically consistent samples, or conclude the evolution.

Optimized via Group Relative Policy Optimization with a homogeneity-aware reward, the agent learns to maximize the diagnostic homogeneity of the support set. On retinal disease benchmarks, Evo-RAD outperforms retinal foundation models by +21.04% and surpasses retrieval-based and parameter-efficient fine-tuning methods by +3.56%.

02 / Action Space

Three agentic actions

a₁ · DELETE
−

Purge discordant evidence

  • Remove hub neighbors polluting the graph.
  • Reject off-manifold, visually-similar mismatches.
  • Break common-disease bias early.
a₂ · INSERT
+

Acquire consistent samples

  • Pull homogeneous cases from external memory.
  • Strengthen diagnostic support for the query.
  • Grow rare-class coverage on demand.
a₃ · TERMINATE
·

Conclude the evolution

  • Halt when the reference graph is coherent.
  • Trigger consensus voting over the purified set.
  • Yield a calibrated diagnostic label.
03 / Method

How Evo-RAD thinks

Pipeline. Given a query image, a top-K retrieval builds an initial graph whose nodes carry image + LLM-generated textual embeddings and whose edges encode adjacency in embedding space. A policy π_θ then evolves the graph via DELETE / INSERT / TERMINATE until a purified graph G* supports the final voted diagnosis.

Retrieval as an MDP

  • Sequential decision instead of one-shot NN.
  • Agent reasons over evidence across time.
  • Similarity score is no longer trusted alone.

Graph-based observer

  • Nodes carry image + text embeddings.
  • Edges encode adjacency in feature space.
  • Three actions edit the graph state.

Homogeneity-aware reward

  • Rewards diagnostic coherence of the set.
  • Pushes toward semantic — not visual — match.
  • Explicit signal against hubness bias.

GRPO training

  • Stable optimization without value critic.
  • Group-relative advantages fit sparse rewards.
  • Matches group-comparison of diagnosis.

Hubness resistance

  • Iterative purging removes hub samples.
  • Rare cases keep their diagnostic voice.
  • Reduces common-disease drag on prediction.

Consensus voting

  • Aggregate over purified graph G*.
  • Calibrated and interpretable output.
  • Human-auditable evidence trail.
